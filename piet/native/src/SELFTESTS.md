# Selftest index

`piet_selftest` (built from `selftest_main.cpp`) with no argument runs the full regression: `runSelftest()` in `selftest.cpp` calls the embedded cases (declared in `selftest_cases.h`) and then the feature cases (76 declared in `selftest_feature_cases.h`, two more declared at their call in `selftest.cpp`) one call per line in a fixed order that is part of the behaviour, e.g. `testW2eFloat` must stay last because it prints a process-wide counter; `piet_native --selftest` starts that same full run. `piet_selftest --list-suites` lists the named subsets and `piet_selftest --suite NAME` runs one (`all`, `tables`, `data-conversion`, `stored-estimates`, `time-declarations`); the subsets are tables of entry-function names in `selftest.cpp`, so a file can be renamed freely but an entry-function name is program output and must not change.

`selftest.cpp` must keep its name and directory: its own `__FILE__` is the anchor (`selftestSourceFile()`) that the cases use to find the repository root and the validation fixtures. Three feature files also locate a fixture from their own path (`selftest_estimation_weights_and_vce.cpp`, `selftest_replication_package_regressions.cpp`, `selftest_string_conversion_destring_tostring.cpp`); rename them only together with that path literal. New case files are named `selftest_<domain>_<feature>.cpp` and need a declaration, a call in `runSelftest()` and a row in the `piet_selftest` source list of `CMakeLists.txt`.

Infrastructure, not case files: `selftest.cpp` (runner, suite tables), `selftest_main.cpp` (entry point, private scratch directory), `selftest_support.h` / `selftest_support.cpp` (shared helpers), `selftest_suites.h`, `selftest_cases.h`, `selftest_feature_cases.h` (declarations).
