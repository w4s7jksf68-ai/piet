# Security

This is experimental local software. Treat scripts as executable code: they can
access files and invoke programs with the privileges of the current user.

For a suspected vulnerability, use GitHub's private vulnerability reporting on
this repository when available. Do not post exploit data, credentials or private
files in public issues. If private reporting is unavailable, open an issue asking
for a private contact without including the sensitive details.

Only the latest public beta is considered for fixes; no response-time guarantee
or long-term support commitment is offered.
