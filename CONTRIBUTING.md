# Contributing

Report the release tag, operating system, commands, expected result and actual
result. Use small synthetic examples. Include a published method or independently
computed answer for numerical discrepancies.

Contributions must be code you have the right to submit under GPL-3.0-or-later.
Identify all third-party code and preserve its license and attribution. Do not
copy proprietary source, manuals, licensed datasets, or private test logs.
Submit focused pull requests with a reproducible verification command.
